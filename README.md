# Karine Salvador · Fisioterapia Esportiva

Landing page estática (HTML + CSS + JS, sem build). Abra `index.html` no navegador ou publique a pasta em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).

## Configurar
- **WhatsApp e Instagram:** edite `CONFIG` no topo de `assets/js/main.js` (número só com dígitos: 55 + DDD + número).
- **Fotos:** coloque em `assets/img/` com estes nomes (enquanto não existirem, aparece um degradê de pôr do sol):
  `hero.jpg` (vertical, 4:5) · `atendimento.jpg` (4:5) · `entre-elas-1.jpg` · `entre-elas-2.jpg` · `rotina-1.jpg` a `rotina-4.jpg` (quadradas)
